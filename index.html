What this site is

This GitHub Pages site (when published) is intended to host only the public legal documents for CPA, a private internal accounting tool used by the Company. It does not host the CPA application, QuickBooks credentials, accounting data, logs, or analytics.

CPA is not a consumer-facing product, marketplace, or marketing website. It is intended for authorized Company use on Company-controlled devices in a QuickBooks Online–licensed environment.

What CPA does (summary)

CPA enables an authorized Owner to connect the Company’s QuickBooks Online company file to Grok Bot (via the Cursor / Grok Bot service) so that financial and accounting transactions can be retrieved and proposed entries can be reviewed. Entries are created or changed in QuickBooks Online only when the authorized user approves them. CPA is not QuickBooks software and is not developed by Intuit; it integrates through the QuickBooks Online API and a local connector process.

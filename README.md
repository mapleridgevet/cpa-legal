# cpa-legal

Static legal pages for CPA, an internal accounting tool of Maple Ridge Mobile Veterinary Services, PLLC. The approved wording is effective November 6, 2026.

- [Home](index.html)
- [Privacy Policy](privacy-policy.html)
- [EULA](eula.html)

Styles are in `styles.css`. Links are relative so the pages resolve at `/cpa-legal/` when GitHub Pages is later served from the `main` branch, folder `/ (root)`.

GitHub Pages is not enabled by this repository. These files do not include the CPA application, connector code, credentials, accounting data, forms, or analytics.
